# 서하린 홈페이지 GitHub 업로드 안내

이 폴더 **안에 있는 36개 파일**을 GitHub 저장소의 최상위에 올리세요. 업로드한 저장소 화면에서 `index.html`이 바로 보여야 합니다.

1. [hellomay83-dev/-AI- 저장소](https://github.com/hellomay83-dev/-AI-)에서 **Add file → Upload files**를 누릅니다.
2. ZIP 파일이나 이 폴더 자체를 올리지 말고, **이 폴더 안의 파일과 `media`, `fonts` 폴더를 모두 선택**해서 업로드합니다.
3. 업로드 목록에 `index.html`, `about.html`, `portfolio.html`, `news.html`, `fan.html`, `contact.html`, `app.js`, `data.js`, `styles.css`, `media/`, `fonts/`가 있는지 확인한 뒤 **Commit changes**를 누릅니다.
4. **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, `main`, `/(root)`를 선택하고 저장합니다.
5. 배포 주소 [https://hellomay83-dev.github.io/-AI-/](https://hellomay83-dev.github.io/-AI-/)를 확인합니다.

가장 큰 파일은 약 2.9MiB이고 전체는 약 14.3MiB입니다. 사진과 영상은 이 폴더에 포함되어 있습니다. 협업 문의·팬 메시지·구독 신청은 현재 공개된 운영 사이트의 접수 화면으로 연결됩니다.

ZIP은 전달·보관용입니다. **GitHub에 ZIP 파일 하나만 업로드하면 홈페이지가 열리지 않습니다.** 먼저 압축을 푼 다음, 안의 파일과 폴더를 업로드하세요.
